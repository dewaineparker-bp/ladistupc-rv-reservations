# LA District RV Reservations

Custom Laravel-based RV reservation system for the Louisiana District UPC campground.

Planned core flow:
- Select arrival and departure dates
- Choose Occupied or Storage pricing mode
- View available RV sites on an interactive campground map
- Select a site and complete reservation
- Process payments through Authorize.net

Administration will include reservation management, site management, rates, map configuration, payments, and reporting.
